외부 시스템 바이너리(FFmpeg, Tesseract) 설치
youtube_api.py의 오디오 WAV 변환은 FFmpeg, pdf_ocr_util.py는 Tesseract OCR 시스템 바이너리가 환경 변수(PATH)에 등록되어 있어야 상위 호출부에서 에러 없이 실행됩니다.  

YouTube API Daily Quota(할당량) 관리
get_playlist_videos에서 비디오가 수백 개 이상인 대형 재생목록을 자주 순회할 경우, YouTube Data API의 일일 기본 할당량(10,000 units)을 빠르게 소진할 수 있으므로 상위 비즈니스 로직에서 캐싱(Caching)을 고려하는 것이 좋습니다.  

대용량 파일 작업 시 진행률(Logging) 추적
백여 페이지가 넘는 스캔본 PDF나 장시간 유튜브 오디오 변환 시 블로킹(동작 멈춤 현상)처럼 보일 수 있으므로, 메인 실행부에서 logging 또는 tqdm 같은 프로그레스 표시를 연결해 두면 유용합니다.
